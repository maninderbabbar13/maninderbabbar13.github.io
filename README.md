# IconicHub Pro

A polished static wallpaper website ready for GitHub Pages.

### Test locally
Open `index.html` in a browser.

### Publish
Upload all files to a public GitHub repository, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

### Add real wallpapers
Put original JPG/PNG files in `images/`, then edit `script.js` so each card's Download link points to the corresponding file.

The current visual cards are CSS demo artwork; they are not external copyrighted wallpapers.
